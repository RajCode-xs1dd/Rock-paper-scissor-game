# 🎮 Rock Paper Scissors Game

A sleek, responsive **Rock, Paper, Scissors** web application featuring a modern 3D neumorphic interface, custom hand physics animations, and seamless dark mode synchronization. 

🚀 **[Play Live Demo Here](https://rajcode-xs1dd.github.io/Rock-paper-scissor-game/)**

![License](https://shields.io)

---

## ✨ Features

- **Premium 3D Interfaces:** Multi-layered elevation shadows provide an immersive physical button feeling.
- **Dynamic Violet Aura Glow:** Smooth CSS active states mirror professional gaming design paradigms.
- **Fluid Micro-Animations:** Responsive layout lifting effects and custom shake cycles enhance game actions.
- **Native Theme Syncing:** Adapts typography and color tones flawlessly between light and dark settings.
- **Adaptive Architecture:** 100% scalable grid structures designed to function seamlessly across mobile viewports and desktops.

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5 Structure
- **Styling:** Modern CSS3 featuring advanced CSS Variables (`:root`), Flexbox layouts, and Custom Bezier Transitions
- **Logic:** Native JavaScript (ES6+) Architecture

Follow these steps to spin up the project locally on your machine:

### 1. Prerequisites
Ensure you have Git installed on your system.

### 2. Clone the Repository
```bash
git clone https://github.com
```

### 3. Open the Project
Navigate into your directory and launch the interface:
```bash
cd "Rock Paper Scissors Game"
# Open index.html in your preferred browser
```
